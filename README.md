# northstar_portal
#### CS446 Project on a deliberately insecure system

## *Everything you need to get work done, all in one place.*

Northstar Workspace is an internal employee portal designed to centralise access to workplace tools, company information, and employee account management.

We are proud of what we’ve built, which is why we’re excited to make our codebase open to the world. We believe great software isn't built in a silo, ideas grow stronger when they are shared. By opening up our code, we want to give back to the developer community, invite transparent collaboration, and empower others to learn, build, and innovate alongside us.

Unfortunately, we are unable to share our more sensitive code base (so some file will not be available).
